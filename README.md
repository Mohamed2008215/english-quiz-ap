# اختبر جملك الإنجليزي — مشروع بناء APK تلقائي

## الخطوات
1. اعمل حساب مجاني على github.com (لو معندكش).
2. اعمل Repository جديد (New repository)، خليه Public، وسيبه فاضي (من غير README).
3. من صفحة الريبو الفاضي، دوس على "uploading an existing file" وارفع كل ملفات المشروع ده
   (حافظ على أسماء الفولدرات: .github/workflows و www بنفس الشكل).
4. بعد الرفع، روح لتبويب "Actions" فوق في الريبو.
5. هتلاقي عملية اسمها "Build Android APK" شغالة أو انتظر لحد ما تبدأ (لو مبدأتش، دوس
   "Run workflow" يدويًا).
6. استنى لحد ما تخلص (علامة صح خضراء)، عادة بتاخد 3-6 دقايق.
7. دوس على العملية اللي خلصت، هتلاقي تحت "Artifacts" ملف اسمه english-quiz-app-apk.
8. حمّله، فك الضغط عنه (zip)، هتلاقي جواه app-debug.apk.
9. انقل الملف لموبايلك وثبّته (وافق على "تثبيت من مصدر غير معروف" لو طلب منك).
